# GROOVE SYNTH GS-1 用户手册

面向演奏者与声音设计者的操作说明。首次使用请先阅读「启动」一节。

---

## 1. 启动

1. 用浏览器打开站点（需 HTTPS 或 localhost）。
2. 点击画面中央的 **「▶ 启动音频引擎」**（或点击任意位置）。
   - 浏览器要求一次用户点击才允许播放声音。
   - 遮罩下方会显示诊断行：`GS-1 vX · SIMD ✓/✗ · WASM simd/scalar · AudioContext running · 48000 Hz`。
3. iPhone/iPad 建议用 Safari 的「添加到主屏幕」以独立窗口运行。

> iPhone 请确认侧边**静音开关**未打开；应用已使用 `playback` 音频会话，但系统音量仍需大于 0。

---

## 2. 演奏

| 操作 | 效果 |
| :--- | :--- |
| 点击 / 按住琴键 | 发声；按住横向滑动可滑奏 |
| 电脑键盘 `A W S E D F T G Y H U J K` | 对应一个八度；`O` `L` 继续向上 |
| `OCT −` / `OCT ＋` | 切换音域；手机自动只显示 1 个八度 |
| 弯音轮（PITCH） | 上下拖动，松手自动回中 |
| 调制轮（MOD） | 上下拖动，映射到调制矩阵的 MODWHEEL 源 |
| 预设库 → 音频设置 | 引擎状态、采样率、输出延迟、DSP 内核、实时负载、**输出设备**（可把声音送到指定耳机/接口），以及**复音数上限**（4/8/16/32，会记住；设备吃力时钉在 8/4 最有效） |
| 撤销 / 重做 | 顶栏 ↶ ↷ 按钮，或 `⌘/Ctrl+Z`、`⇧⌘/Ctrl+Shift+Z` / `Ctrl+Y`；覆盖音色参数、模块折叠与视图切换、信号流节点位置与重置、用户预设与片段的删除 |
| 「▶ 播放器」 | 打开 MIDI 播放器：内置曲目、导入、录制、导出 MIDI/MP3 |
| 预设库 → 更新记录 | 查看当前版本与历史版本的更新内容（离线，随应用一起打包） |

### MIDI

点击顶栏 **MIDI** 授权后即可使用外部 MIDI 键盘 / 控制器：
- **MIDI 输出**（音频设置）：把演奏发送到外部设备（硬件合成器 / 鼓机 / DAW），选好端口再打开开关；关闭时先发 all-notes-off。

- 音符力度映射到包络；
- 弯音轮（Pitch Bend）映射到音高；
- CC1 调制轮、CC64 延音踏板（松开踏板才释放延音）、CC123 全部音符关闭。
- **CC Learn（预设库 → 音频设置）**：选一个控件 → 点「学习」→ 转动控制器上的旋钮即完成映射；对数控件按对数缩放、步进控件取整，映射会记住并可单独清除（CC1/CC64 未映射时仍保留调制轮与延音功能）；
- **MPE（音频设置）**：开启后每个音拥有**独立弯音**（控制器每音一通道时，通道弯音只作用于该音）；关闭时所有弯音立即复位；
- **力度曲线（预设库）**：线性 / 柔和 / 强硬，只影响实时演奏（触摸屏与 MIDI），曲目播放保持原谱力度。

## 3. 模块

每个模块标题栏右侧有两个按钮：

- **⠿ 拖拽手柄**：按住拖动即可把模块放到任意位置（顺序会被记住）；
- **▾ / ▸**：收起 / 展开模块。

模块说明：

| 模块 | 内容 |
| :--- | :--- |
| OSC 1 / OSC 2 | 波形（正弦/三角/锯齿/方波/脉冲/噪声）、音高、微调、电平、脉宽、声像（两个振荡器 PAN **不同**时自动进入每振荡器独立滤波的真立体声）、**UNI**（1–7 层 Unison 叠层）、**SPREAD**（失谐散布，最大 ±35 音分；复音上限会按层数自动折算）；OSC 1 上另有 **FM**（OSC 2 对 OSC 1 的相位调制深度）与 **RING**（两振荡器环形调制量） |
| FILTER | 类型 LP/HP/BP/NT、截止、共振、驱动、包络量、键盘跟踪、频响曲线 |
| AMP ENV | 振幅 ADSR（可拖动手柄）+ FILTER ENV 独立包络 + POLY/MONO/LEGATO + GLIDE |
| LFO | LFO 1 与 LFO 2：波形、速率、深度、目标（截止/音高/音量/脉宽）、同步 |
| MOD MATRIX | 调制路由（8 槽，源 → 目标 + 双极深度 + 开关，可增删）。源：LFO / LFO2 / ENV / 调制轮 / 力度 / 触后 / 每音随机 / 键位跟踪；目标：截止 / 音高 / 音量 / PWM / 声像 / 共振 |
| FX | **信号链**（`‹` `›` 调换效果顺序，`∥` 把插入式效果改为并联送出）、混响（ALGO 算法 / IR 卷积二选一；算法侧 SIZE 衰减 / MIX 干湿 / DAMP 尾音阻尼 / WIDTH 立体声宽度 / PRE 预延迟，IR 侧导入脉冲响应 + TRIM）、延迟（同步分频、反馈、混合、DAMP 回声变暗、PING-PONG 左右交替） |
| FX 2 | 合唱、镶边、移相、过载 |

### 噪声音色

- 波形里的 `NOI` **白噪**（每个频段能量相同）、`PNK` **粉噪**（每倍频程 −3 dB）、`BRN` **棕噪**（−6 dB）；
- 做风声、海浪、鼓的噪声层时粉噪/棕噪比白噪自然得多；
- 波形最后一项 `WT` 是**波表振荡器**：五张由谐波构成的表（风琴 / 中空 / 人声 / 金属 / 玻璃），每张按八度分层抗混叠；**用 `PW` 旋钮切换表**（波表没有脉宽）。

### 数据格式与向后兼容

- 音色存档、分享链接、工作区设置、场景、导入的波形与 IR 都记录**格式版本号**；
- 升级后旧数据会自动按当前格式读取，缺的字段用默认值补齐，因此不会出现「某个参数悄悄回到默认」；
- 若存档来自**更新的版本**（例如你曾用过新版再回退），程序会回退到初始状态并把原存档另存为 `gs1:state:v1.newer`，新版可以再取回；分享链接同理会被拒绝而不是读错参数。

### 卷积混响（IR）

混响单元顶部有 `ALGO` / `IR` 两个引擎：

| 控件 | 说明 |
| --- | --- |
| ALGO | 自研算法混响（SIZE / DAMP / WIDTH / PRE 可调），CPU 占用低，适合大多数音色 |
| IR | 卷积混响：导入一段脉冲响应，用真实空间（或硬件）的采样做混响 |
| 导入 IR | 选音频文件（WAV / AIFF / FLAC / MP3）。建议单声道、≤ 2 秒；超长会截断 |
| TRIM | 湿声大小。IR 按**能量归一化**，所以不同文件之间干湿比可比 |
| ✕ | 移除导入的 IR（本机保存随之清除） |

- IR 是**乐器级设置**（所有音色共用一份，保存在本机），`ALGO`/`IR` 的选择属于音色；
- 湿声会比干声晚约 21 ms——这相当于一段固定的预延迟，干声不受影响，所以不会产生梳状滤波；
- 未导入 IR 时选 `IR` 会自动回落到算法混响，音色不会变哑。

### 曲库与录制

- 播放器里的**内置曲目**来自程序本身；**导入的 MIDI 文件**与**录制片段**保存在本机（`localStorage`），重开页面后仍在，并保持上次选中的曲目；
- 最多保留 12 首用户曲目，超出后只保留最近的；单曲过大时只在本次会话有效（避免占满浏览器存储）；
- 曲库与音色存档一样带格式版本号：来自更新版本的曲库文件会被忽略，不会读出一半；
- **损坏或不完整的 MIDI 文件**（下载中断、传输出错）不会让导入失败：能读出的音符照常放进来，
  缺字节的地方忽略，超出范围的音符/力度/速度会被夹回合法值；完全读不出音符时才提示「文件里没有音符」。

### 效果信号链

FX 模块顶部的「信号链」一行是效果的**处理顺序**，从左到右依次处理：

| 操作 | 说明 |
| --- | --- |
| `‹` `›` | 与相邻位置交换。链条是六种效果的一个排列，所以不会丢效果、也不会重复 |
| `∥` | **并联送出**：效果声叠加在干声上（干声原封不动）；不按时是**插入式**，效果与干声交叉淡化。延迟与混响本身就是叠加送出，所以没有这个开关 |

- 默认顺序是历史上一直使用的顺序（延迟 → 混响 → 合唱 → 镶边 → 移相 → 过载），因此旧音色听起来完全不变；
- 顺序、并联开关都属于**音色**的一部分：预设、场景、分享链接、撤销重做都会带上；
- 典型用法：「过载 → 延迟」让回声也带失真；「延迟 → 过载」则是把整段（含回声）一起推饱和；「混响 → 过载」会让尾音也脏起来。

### 采样音源（SMP）

波形里的 `SMP` 是**采样振荡器**：导入一段音频当音源，按音高变速播放。

| 控件 | 说明 |
| --- | --- |
| 导入采样 | 选音频文件（WAV/AIFF/FLAC/MP3）。超过 **4 秒**会截断；超过 32 个采样才会被接受 |
| ROOT | 这段音频**原本的音高**（按下的音符等于 ROOT 时按原速播放，其它音符按比例变速） |
| ONE | 一次性：放完即停（鼓、音效） |
| LOOP | 循环：到循环终点跳回起点（持续音） |
| P-P | 乒乓循环：到两端反向（铺底、磁带感） |
| LOOP A / B | 循环起止点（占整段的比例），只在 LOOP / P-P 下出现 |
| ✕ | 移除导入的采样 |

- 采样按**八度分层抗混叠**：每个 mipmap 级只保留该音高能容纳的频带，所以高音区不会出现折叠噪声；
- 采样是**乐器级设置**（所有音色共用一份，保存在本机）；`ROOT`、模式与循环点属于音色；
- 波表预览会画出采样本身；音频导出（WAV/MP3）会一并渲染；
- 没有导入采样时选 `SMP` 是**静音**（不会拿噪声或别的波形冒充采样）。

### 导入自己的波形（波表）

选 `WT` 后，振荡器下方会出现一行导入控件：

| 控件 | 作用 |
| --- | --- |
| 导入波形 | 选一个音频文件（WAV / AIFF / FLAC / MP3 等）。只有**一个周期**的文件会直接使用；文件里有多个周期时，会自动找出周期、对齐并平均若干周期，噪声因此更低 |
| 使用 | 切换「用导入的波形 / 用内置五张表」。导入后会自动打开；它和音色一起保存，所以预设、场景、分享链接都能记住这个开关 |
| ✕ | 移除导入的波形（本机保存随之清除） |

- 波形是**乐器级设置**，所有音色共用一份，保存在本机（`localStorage`），重开页面仍在；
- 波表预览会画出导入的波形本身（不再是内置表的示意形状）；
- 音频导出（WAV / MP3）会把导入的波形一起渲染，导出结果与现场听到的一致；
- 采样精度是 16 bit（分析成 1024 次谐波之前，量化噪声已在可闻之下）；
- 单周期最好来自波表编辑器或「导出单周期」的音频，长度任意；太短、静音或含无效采样的文件会被拒绝并提示原因。

### 旋钮操作

旋钮会根据你正在使用的设备切换两套手势：

| 操作 | 桌面（鼠标） | 触屏（手指） |
| --- | --- | --- |
| 调节 | 上下拖动 | 上下拖动（灵敏度更慢，带数值气泡） |
| 微调 | `Shift` + 拖动 | **长按 0.6 秒**再拖动（数值显示「微调」） |
| 快速微调 | 滚轮 | — |
| 复位 | 双击 | 双击 |
| 键盘 | 方向键调节，`Home` 复位 | — |

### 包络数值直接编辑

AMP ENV / FILTER ENV 下方的 A / D / S / R 数值格支持三种操作：

- **单击** → 进入输入状态，光标停在末尾（不会选中原值），直接键入数字后 `Enter` 或点空白处提交；
- **长按或上下拖动** → 像旋钮一样调节（手机上没有键盘弹出），桌面端 `Shift` 更精细；
- **滚轮 / 方向键** → 微调（桌面），`Esc` 取消输入。

A/D/R 以毫秒输入，S 以百分比输入。

### 拖动包络图上的控制点

AMP ENV / FILTER ENV 的曲线图上有 A / D / S / R 四个圆点，可直接拖动：

- **触屏**：在圆点附近约 50px 内按下就会吸附到最近的点并开始拖动，不需要精确点中圆点；拖动时保持手指与圆点的相对偏移，不会突然跳变；
- **桌面**：鼠标靠近圆点即可抓取；
- 横向拖动 A / D / R 改变时间，纵向拖动 S 改变延音电平。

> 触屏设备底部键盘旁会显示一行手势提示，内容与桌面版不同（不包含 `Shift`、滚轮等鼠标操作）。

## 4. 预设与音色管理

- 顶栏 `‹` `›` 切换预设，点击中间显示区打开 **预设库**；
- 预设库支持搜索、分类筛选、点击载入；
- 内置 **77 个工厂预设**，覆盖 LEAD / BASS / PAD / PLUCK / KEYS / FX / BASIC 七类：既有单音滑音主音、
  Reese 咆哮、铺底、卡林巴、电钢、上升音，也有**超流行主音、未来和弦、合成波贝斯、Phonk 牛铃、Drill 808、
  氛围绽放、机器人声、芯片主音、水晶玻璃、摇摆低音**等现代音色；
- **所有预设响度已统一**（实测差异 < 4 dB），换音色不会突然变大或变小；每音色的出厂校准是内部的，
  与你自己在 AMP 里设的 VOLUME 互不影响；
- 预设库里的「**调律**」可选平均律 / 纯律 / 毕达哥拉斯律 / 中庸律，或「**导入 .scl**」载入 Scala 调律文件
  （任意音数、非八度周期）；「**力度曲线**」见上文 MIDI 一节；
- 预设库底部的 **EN / 中文** 按钮可切换界面语言（会记住）；英文界面下预设只显示英文名；
- **场景**：把当前**工作区**（模块顺序与折叠、当前视图、信号流节点位置/隐藏）存成命名场景并一键切回；语言、配色、触感、MIDI 映射等个人偏好不受影响；
- **随机**：生成一个新音色；
- **保存**：把当前音色存入本地预设库（保存在浏览器 `localStorage`）；
- 预设库底部：
  - **使用指南**：打开内置手册（合成器基础、新手教学、使用帮助、从零捏音色），全离线；
  - **导入 / 导出**：`.gs1.json` 文件（导出的是当前音色；导入的文件会立刻生效并在顶栏显示它自己的名字，
    `.gs1song` 编曲文件也从这里导入）；无法识别的文件会提示「文件格式无法识别」，当前音色不变；
  - **分享**：把当前音色编码进 URL 分享给他人；
  - **重置布局**：恢复模块顺序、展开状态与键盘显示。

### A/B 对比与撤销

- 顶栏 **A / B**：两个音色槽。首次点击某槽会保存当前音色；之后点击即可在 A/B 之间切换，**⇄** 把当前音色复制到另一槽；
- **↶ / ↷**：撤销 / 重做，快捷键 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`（或 `Ctrl/Cmd + Y`）。

## 5. 悬浮键盘

- 键盘固定在视窗最下方，不随页面滚动；
- **多指和弦**：可同时按下多个琴键（例如三根手指弹一个三和弦），每个手指独立跟踪，最多到当前复音上限；
- 点顶栏 **键盘** 按钮或键盘右上角 ⌃ 隐藏；隐藏后右下角出现「⌨ 键盘」悬浮按钮；
- 键盘上方可切换八度（`OCT −` / `＋`）；
- 手机与平板会自动隐藏弯音轮并把操作提示移到键盘下方，把横向空间全部留给琴键；
- **力度（VEL）**：触屏设备上点 `力度` 按钮开启后，按键位置决定力度——越靠近琴键下缘越响（0.35–1.0），监视器显示 `VEL 0–127`；关闭时所有音均为固定力度；
- **振动（HAP）**：支持振动马达的设备（主要是 Android）可开关键盘触感反馈；Safari / iOS 没有网页振动接口，按钮会自动隐藏，功能静默降级；
- 手机横屏、iPad 竖屏：操作提示排在键盘下方，模块区为两列。

### 设备布局

- **监视器读数**：VU 表下方小字依次是 **峰值 dB · 响度 dB · DSP 负载%**（鼠标悬停有说明）。负载长期接近 100% 说明设备吃力，可降低复音或先关掉效果；超过约 35% 引擎会自动减少复音，单块吃满预算时立刻降 8 个声部。
- **手机竖屏**：顶栏一行放品牌与常用动作（键盘、钢琴卷帘等在「⋯」里），预设独占一行，视图切换再占一行；监视区收成一条紧凑条（音符/和弦、播放、VU），点右侧箭头展开示波器与频谱。
- **手机横屏**：顶栏压成一行（视图切换并入行尾），监视条额外显示实时波形与频谱。
- **iPad 竖屏**：品牌、视图切换与常用动作一行，预设独占一行；监视区默认是带波形与频谱的紧凑条；模块两列全部展开。

### MIDI 播放器

监视区的 **播放器** 按钮打开播放器面板：

- **内置 20 首**：致爱丽丝、卡农、月光奏鸣曲（第一乐章）、梦中的婚礼、土耳其进行曲、

  以及琶音、音阶两条练习素材；
- **录制量化**：传输条上的「量化」可选十六分 / 八分 / 八分三连 / 四分；**停止录制时**把该次演奏对齐到网格（音符长度与相对位置不变），已有曲目与导入文件不受影响；
- **导入 MIDI**：支持标准 MIDI 文件（`.mid` / `.midi`，格式 0/1），自动合并多轨并读取速度与音轨名；
- **播放控制**：播放 / 暂停、停止、循环、拖动进度条、速度 0.5–1.5×、移调 ±12 半音；
  播放使用当前音色，边播边换预设即可听到同一旋律的不同配器；
- **A/B 循环**：播放到想要反复的地方点 **A** 设起点、再点 **B** 设终点，进度条上会亮出这一段并自动进入循环（点 **AB** 清除）；练难点片段很方便；
- **节拍器**：点节拍器图标开启，每拍一响（每小节第一拍重音），走独立音频通道，不经过音色、不进录制与导出；开启后旁边出现 **1·2** 按钮，可在正式播放前先数一小节预备拍；
- **片段编排**：层条上的「折叠成片段」把这一层变成一个**片段**（循环窗口对齐到整小节，所以折叠后听起来完全一样）。
  选中片段后可以：`◀ ▶` 前后移一个窗口、`⧉` 复制、`− +` 改循环窗口长度、`×− ×+` 加减铺排次数、`✕` 删除；
  片段块画在层条上方，宽度是它铺排的整段，每一处循环画一条分隔线。**窗口变短时超出的音符不再播放，加长就回来了**
  （片段保存的是完整材料，窗口只是播放范围）；多个片段重叠时都发声。片段内部的音符仍用**钢琴卷帘**编辑
  （工具栏的「片段」选择器切换片段，卷帘里改的就是该片段的内容，改动会立即反映到每一次循环）。
  被折叠的那一层按片段播放；**没被折叠的层照原样播放**。导出 MIDI / WAV / MP3 都跟随编排
  （MIDI 导出的是展开后的演奏，所以 MIDI 文件里没有片段结构，重新导入会变成平面音符）；
- **多轨与分层**：格式 1 的 MIDI 保留轨道分层，每条轨道一行，可单独静音 / 独奏 / 调音量 / 调**声像**
  （把某层推左或推右，两层各占一边更好分辨；声像与音量一样属于这首曲子，重开仍在；手弹的音符始终居中）；
  每行左侧的**缩略时间线**画出该层音符与播放头，它有两种模式（时间线左上角的按钮切换）：
  **编排**（默认，也是它一直以来的行为）——**点一下**把播放位置跳到那一点，**左右拖动**整层前后移动
  （最多各一分钟；被推到起点之前的音符不再发声、也不再画出），挪动量随曲目保存，重开仍在；
  **音符**——直接在时间线上改音符：点选、**拖动改位置**、**拖右缘改长度**、**双击删除**，
  都按 1/16 吸附并限制在曲目范围内；选中后下面出现一排按钮（`◀ ▶` 提前/推后一格、`− +` 缩短/加长一格、`✕` 删除），
  手机上不拖拽也能改；这里和钢琴卷帘是**同一份数据、同一套撤销**——在时间线上挪一个音，打开卷帘就在新位置，
  在卷帘里 `Ctrl/Cmd+Z` 也能把它撤回去；改动立刻随曲目保存，重开仍在。内置示范曲目不能改，
  第一次编辑会自动存成副本继续编辑（会提示一次）；
- **录制**：点 ● 用键盘或 MIDI 控制器演奏，再点 ■ 结束；录制会忽略播放器自身输出；
- **分享整首编曲**：预设库的「分享」会把**当前曲目 + 层混音**（静音/独奏/音量/声像/时间偏移）一起放进链接，
  链接会先压缩（五分钟曲目约 1.5 KB，比以前小约 96%），
  对方打开就能看到同一首曲子并按同样的混音播放；曲目太长时自动改为下载 `.gs1song` 文件，对方用「导入」打开；
  内置示范曲不参与分享；MIDI 导出与 WAV/MP3 导出同样遵循当前混音（见上）；
- **启动**：第一次点「启动音频引擎」后即进入；若浏览器当时不让出声（Firefox 的自动播放策略、iOS 被通话/其它 App 占用），
  会出现「点按恢复声音」提示，点一下或直接弹琴/播放即可恢复；
- **导出 MIDI**：保存为 `.mid`；**导出的是当前混音**——静音/独奏决定哪些层留下，音量写进力度，
  时间偏移写进时间，声像写进 CC10，多于一轨时仍是 format 1（每层一轨）；
- **导出 WAV（无损）**：与 MP3 相同流程但不经过编码器，文件更大；用来判断听感问题是编码造成还是播放设备造成。
  两者都按当前层混音渲染（静音/独奏/音量/声像/时间偏移），所以导出的就是听到的编曲；
- **导出 MP3**：用当前音色离线渲染整首曲目，导出前把峰值归一化到 −1 dBFS（安静音色会被提升到正常音量，避免播放端大幅加增益引入噪声），再编码为 256 kbps MP3；录制片段换音色后可重新导出。

### 钢琴卷帘编辑器

编辑当前曲目：

### FM、环形调制与硬同步

OSC 1 模块里的 **FM / RING / SYNC** 决定 OSC 2 怎么塑形 OSC 1，**NOISE** 把白噪混进来；每个振荡器还有自己的 **SUB**：

- **FM**：OSC 2 推动 OSC 1 的**相位**（经典 FM）。比例用 OSC 2 的 PITCH/DETUNE 设；把 OSC 2 的 LEVEL 关掉就是纯 FM。
- **RING**：两个振荡器**相乘**（铃声、非谐音色），强度由两个 LEVEL 决定。
- **SYNC（硬同步）**：OSC 2 每完成一个周期就把 OSC 1 的相位拉回起点，得到经典的「同步主音色」——用 OSC 2 的 PITCH 扫比例就是那个标志性的扫频；OSC 1 自己的 PITCH 决定音高。相位重启做了抗混叠（2 倍过采样 + 抗混叠滤波 + 亚采样精度对齐），所以不会撒出刺耳的宽带噪声。
- **SUB / SUB LVL**：每个振荡器一条低一个或两个八度的正弦，专门补低频（正弦没有谐波，不会糊）。SUB LVL 相对该振荡器自己的 LEVEL。
- **NOISE**：把白噪混进这一声部（在滤波器之前，所以滤波器会一起塑形）。
- 前三个需要 **OSC 2 打开**；全部默认关闭，老音色不受影响。FM/RING/SYNC 都能被调制矩阵驱动（目标列表里有 FM 与 RING）。

### FM 与环形调制

OSC 1 模块里的 **FM** 与 **RING** 两个旋钮决定 OSC 2 怎么塑形 OSC 1（都默认 0，等于没有）：

- **FM**：OSC 2 推动 OSC 1 的**相位**，也就是常说的 FM/PM。音色比例由 OSC 2 的 **PITCH / DETUNE** 决定
  （+12 = 1:2、+19.02 ≈ 1:3、+7 ≈ 1:1.5……）；**把 OSC 2 的 LEVEL 关掉就是纯 FM**——调制器本身不发声，
  只贡献边带，这也是最经典的玩法。深度越大，边带越多、越亮、越金属；深到一定程度会进入噪音般的区域，
  这正是 FM 的特点。
- **RING**：把两个振荡器**相乘**（环形调制）。它把能量搬到两个频率的**和**与**差**上，载波与调制器本身被抵消，
  所以听起来是铃声、金属、非谐音色。两个振荡器的 **LEVEL** 决定它的强度——把其中一个关掉，环形调制也随之消失
  （要纯环形调制：两个 LEVEL 都开着、RING 拉满）。
- 两者可以同时用，也都能被调制：调制矩阵的目标列表里现在有 **FM** 与 **RING**，把 ENV 接到 FM 就是
  「包络扫亮度」的经典 FM 音色，把 LFO 接到 RING 就是颤动的铃声。FM/RING 需要 **OSC 2 打开**。
- 噪声与采样波形没有“相位”，所以 FM 对它们无效（RING 对任何波形都有效）。

## 9. 故障排查

- **没声音**：先看启动界面显示的版本号；若浏览器缓存了旧版页面，预设库里的「**检查更新**」可强制更新，应用在启动失败时也会自动清理缓存并重载一次；
- **静音时表头显示「— · —」**：这是正常的（−60 dB 以下按静音显示），一旦有声音就会恢复成真实读数；
- **偶发"设备负载偏高"**：只有**持续**过载（连续多块超预算）才会自动降低复音；瞬时尖峰不会。负载高于 5% 才会显示百分比；
- **导出文件太轻或太重**：导出会自动归一化到 −1 dBFS，安静音色也会被提升，不需要额外增益。


| 现象 | 处理 |
| :--- | :--- |
| 没有声音 | 点击「启动音频引擎」；检查系统/浏览器音量与 iOS 静音开关 |
| iPhone/iPad 无声 | 点按界面任意处恢复被挂起的音频；确认未处于静音模式 |
| 琴键无反应 | 刷新页面；若仍无反应请附上控制台报错与诊断行 |
| 负载过高 / 断音 | 应用会自动降低复音上限（监视区出现 `POLY n` 提示），稍后自动恢复 |
| 更新后仍是旧版 | 清除站点数据或强制刷新一次 |
