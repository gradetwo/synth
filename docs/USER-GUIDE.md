# GROOVE SYNTH GS-1 用户手册

面向演奏者与声音设计者的操作说明。首次使用请先阅读「启动」一节。

---

## 1. 启动

1. 用浏览器打开站点（需 HTTPS 或 localhost）。
2. 点击画面中央的 **「▶ 启动音频引擎」**（或点击任意位置）。
   - 浏览器要求一次用户点击才允许播放声音。
   - 遮罩下方会显示诊断行：`GS-1 vX · SIMD ✓/✗ · WASM simd/scalar · AudioContext running · 48000 Hz`。
3. iPhone/iPad 建议用 Safari 的「添加到主屏幕」以独立窗口运行。

> iPhone 请确认侧边**静音开关**未打开；应用已使用 `playback` 音频会话，但系统音量仍需大于 0。

---

## 2. 演奏

| 操作 | 效果 |
| :--- | :--- |
| 点击 / 按住琴键 | 发声；按住横向滑动可滑奏 |
| 电脑键盘 `A W S E D F T G Y H U J K` | 对应一个八度；`O` `L` 继续向上 |
| `OCT −` / `OCT ＋` | 切换音域；手机自动只显示 1 个八度 |
| 弯音轮（PITCH） | 上下拖动，松手自动回中 |
| 调制轮（MOD） | 上下拖动，映射到调制矩阵的 MODWHEEL 源 |
| 「▶ 播放器」 | 打开 MIDI 播放器：内置曲目、导入、录制、导出 MIDI/MP3 |

### MIDI

点击顶栏 **MIDI** 授权后即可使用外部 MIDI 键盘 / 控制器：

- 音符力度映射到包络；
- 弯音轮（Pitch Bend）映射到音高；
- CC1 调制轮、CC64 延音踏板（松开踏板才释放延音）、CC123 全部音符关闭。

## 3. 模块

每个模块标题栏右侧有两个按钮：

- **⠿ 拖拽手柄**：按住拖动即可把模块放到任意位置（顺序会被记住）；
- **▾ / ▸**：收起 / 展开模块。

模块说明：

| 模块 | 内容 |
| :--- | :--- |
| OSC 1 / OSC 2 | 波形（正弦/三角/锯齿/方波/脉冲/噪声）、音高、微调、电平、脉宽、声像 |
| FILTER | 类型 LP/HP/BP/NT、截止、共振、驱动、包络量、键盘跟踪、频响曲线 |
| AMP ENV | 振幅 ADSR（可拖动手柄）+ FILTER ENV 独立包络 + POLY/MONO/LEGATO + GLIDE |
| LFO | LFO 1 与 LFO 2：波形、速率、深度、目标（截止/音高/音量/脉宽）、同步 |
| MOD MATRIX | 调制路由（源 → 目标 + 量 + 开关），可增删 |
| FX | 混响、延迟（含同步分频、反馈、混合） |
| FX 2 | 合唱、镶边、移相、过载 |

### 旋钮操作

旋钮会根据你正在使用的设备切换两套手势：

| 操作 | 桌面（鼠标） | 触屏（手指） |
| --- | --- | --- |
| 调节 | 上下拖动 | 上下拖动（灵敏度更慢，带数值气泡） |
| 微调 | `Shift` + 拖动 | **长按 0.6 秒**再拖动（数值显示「微调」） |
| 快速微调 | 滚轮 | — |
| 复位 | 双击 | 双击 |
| 键盘 | 方向键调节，`Home` 复位 | — |

### 包络数值直接编辑

AMP ENV / FILTER ENV 下方的 A / D / S / R 数值格支持三种操作：

- **单击** → 进入输入状态，光标停在末尾（不会选中原值），直接键入数字后 `Enter` 或点空白处提交；
- **长按或上下拖动** → 像旋钮一样调节（手机上没有键盘弹出），桌面端 `Shift` 更精细；
- **滚轮 / 方向键** → 微调（桌面），`Esc` 取消输入。

A/D/R 以毫秒输入，S 以百分比输入。

### 拖动包络图上的控制点

AMP ENV / FILTER ENV 的曲线图上有 A / D / S / R 四个圆点，可直接拖动：

- **触屏**：在圆点附近约 50px 内按下就会吸附到最近的点并开始拖动，不需要精确点中圆点；拖动时保持手指与圆点的相对偏移，不会突然跳变；
- **桌面**：鼠标靠近圆点即可抓取；
- 横向拖动 A / D / R 改变时间，纵向拖动 S 改变延音电平。

> 触屏设备底部键盘旁会显示一行手势提示，内容与桌面版不同（不包含 `Shift`、滚轮等鼠标操作）。

## 4. 预设与音色管理

- 顶栏 `‹` `›` 切换预设，点击中间显示区打开 **预设库**；
- 预设库支持搜索、分类筛选、点击载入；
- 内置 67 个工厂预设，覆盖 LEAD / BASS / PAD / PLUCK / KEYS / FX / BASIC 七类，
  包含单音滑音主音、Reese 咆哮、合唱/微光铺底、卡林巴、电钢、上升音等音色；
- 预设库底部的 **EN / 中文** 按钮可切换界面语言（会记住）；英文界面下预设只显示英文名；
- **随机**：生成一个新音色；
- **保存**：把当前音色存入本地预设库（保存在浏览器 `localStorage`）；
- 预设库底部：
  - **使用指南**：打开内置手册（合成器基础、新手教学、使用帮助、从零捏音色），全离线；
  - **导入 / 导出**：`.gs1.json` 文件；
  - **分享**：把当前音色编码进 URL 分享给他人；
  - **重置布局**：恢复模块顺序、展开状态与键盘显示。

### A/B 对比与撤销

- 顶栏 **A / B**：两个音色槽。首次点击某槽会保存当前音色；之后点击即可在 A/B 之间切换，**⇄** 把当前音色复制到另一槽；
- **↶ / ↷**：撤销 / 重做，快捷键 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z`（或 `Ctrl/Cmd + Y`）。

## 5. 悬浮键盘

- 键盘固定在视窗最下方，不随页面滚动；
- **多指和弦**：可同时按下多个琴键（例如三根手指弹一个三和弦），每个手指独立跟踪，最多到当前复音上限；
- 点顶栏 **键盘** 按钮或键盘右上角 ⌃ 隐藏；隐藏后右下角出现「⌨ 键盘」悬浮按钮；
- 键盘上方可切换八度（`OCT −` / `＋`）；
- 手机与平板会自动隐藏弯音轮并把操作提示移到键盘下方，把横向空间全部留给琴键；
- **力度（VEL）**：触屏设备上点 `力度` 按钮开启后，按键位置决定力度——越靠近琴键下缘越响（0.35–1.0），监视器显示 `VEL 0–127`；关闭时所有音均为固定力度；
- **振动（HAP）**：支持振动马达的设备（主要是 Android）可开关键盘触感反馈；Safari / iOS 没有网页振动接口，按钮会自动隐藏，功能静默降级；
- 手机横屏、iPad 竖屏：操作提示排在键盘下方，模块区为两列。

## 6. 播放器与信号流

### MIDI 播放器

监视区的 **播放器** 按钮打开播放器面板：

- **内置 16 首**：致爱丽丝、卡农、月光奏鸣曲（第一乐章）、梦中的婚礼、土耳其进行曲、
  River Flows in You、Summer、克罗地亚狂想曲、天空之城、超级玛丽主题曲、权力的游戏主题曲、
  茉莉花、梁祝（选段）、沧海一声笑，以及琶音、音阶两条练习素材；
- **导入 MIDI**：支持标准 MIDI 文件（`.mid` / `.midi`，格式 0/1），自动合并多轨并读取速度与音轨名；
- **播放控制**：播放 / 暂停、停止、循环、拖动进度条、速度 0.5–1.5×、移调 ±12 半音；
  播放使用当前音色，边播边换预设即可听到同一旋律的不同配器；
- **录制**：点 ● 用键盘或 MIDI 控制器演奏，再点 ■ 结束；录制会忽略播放器自身输出；
- **导出 MIDI**：保存为 `.mid`；
- **导出 MP3**：用当前音色离线渲染并编码为 192 kbps MP3，录制片段换音色后可重新导出。

> 内置曲目为简短示范片段，版权归原作者所有；古典与民乐为公版作品。

### 信号流视图

顶栏 **模块 / 信号流** 切换视图。信号流画布中每个节点代表一个处理单元
（OSC 1、OSC 2、FILTER、AMP ENV、LFO、LFO 2、MATRIX、FX、FX 2、OUT），节点内的迷你画面
实时显示波形、滤波响应、包络、LFO 形状、矩阵路由或效果衰减。

- **拖拽**节点自定义布局，位置会记住；手机竖屏默认两列；
- **缩放**：顶栏 `−` / `%` / `+` / `⤢`，桌面端 `Ctrl/Cmd + 滚轮`；打开时自动适应全部节点；
- 带电源图标的节点可一键**旁通 / 启用**，旁通时节点变灰并显示 `BYPASS`；
- **✕ 移除**节点，底部面板保留按钮可随时加回；**重置画布**恢复默认；
- 点节点或 **⤢** 打开右侧参数面板，里面是该模块的完整控件；
- 顶部**性能条**就是演奏模式：选曲、播放/暂停/停止/循环、录制、导出 MIDI / MP3。

### 和弦识别

同时按住两个以上音符时，监视器从 `NOTE` 自动切换为 `CHORD` 并显示和弦名

## 7. 离线与更新

- 首次访问后即可**完全离线**使用（界面、音色库、DSP 全在本地）；
- 发布新版本后，界面右下会弹出「新版本已就绪 · 立即更新」，点击后更新并重载，不会打断正在演奏的声音；
- 顶栏的 **⚙/高对比度** 开关可切换更适合强光环境的高对比配色。

## 9. 故障排查

| 现象 | 处理 |
| :--- | :--- |
| 没有声音 | 点击「启动音频引擎」；检查系统/浏览器音量与 iOS 静音开关 |
| iPhone/iPad 无声 | 点按界面任意处恢复被挂起的音频；确认未处于静音模式 |
| 琴键无反应 | 刷新页面；若仍无反应请附上控制台报错与诊断行 |
| 负载过高 / 断音 | 应用会自动降低复音上限（监视区出现 `POLY n` 提示），稍后自动恢复 |
| 更新后仍是旧版 | 清除站点数据或强制刷新一次 |
