# 硬同步的混叠：一个还没做完的验收项（P6.2b）

v1.84.0 交付了硬同步、sub 振荡器与噪声混合，但 P6.2 的验收里有一条**没有达成、也没有被门禁断言**：

> 频域（同步扫描的谐波结构与混叠 ≤ −60 dB）

## 已证实可用（有断言）

- **同步确实锁相**：主振 220 Hz、从振 1.41×（非整数比）时，输出与「延后一个主周期的自己」相关系数 0.99（未同步时 0.24–0.50）；
- **从振自己的频率让位给主振网格**：未同步时 310 Hz 分量 0.037，同步后 0.00000（>20× 抑制）；
- **非整数比时才该抑制**（整数比本身就在网格上，这是正确行为，测试已按此区分）；
- **sub**：比基频低一个/两个八度，只有一条正弦（220 Hz 处比无 sub 高 50×，110 Hz 处 <1%），电平可控；
- **噪声混合**：非谐波能量 +55 dB，基频位置不动。

## 为什么混叠数字不可信

我最初的度量是「不在 220 Hz 谐波网格上的能量 / 总能量」，用 10 Hz 步长的单 bin 窗 DFT。这个度量**对任何信号都不成立**：

| 信号（220 Hz） | 该度量给出的「离网能量」 |
| :--- | ---: |
| 干净正弦 | −60 dB |
| 干净锯齿（门禁测得其混叠 −84 dB） | −41 dB |
| 硬同步锯齿 | −24 … −33 dB |

干净锯齿根本没有 41 dB 的混叠（现有门禁用另一种方法测得 −84 dB）。换成「整秒 + 矩形窗 + 精确谐波 bin」后，合成周期锯齿给出 −285 dB（度量本身正确），但引擎输出仍是：正弦 −60 dB、锯齿 −41 dB、同步 −24 dB。也就是说：**引擎输出在这一秒里不是严格周期的**，而那个「非周期性」的量级（−40…−60 dB）比我们想测的混叠（−60 dB）还大 —— 在这个噪声底之上无法断言 −60 dB。

下一步该做的（P6.2b，已写进 `docs/NEXT-PLAN.md`）：

1. 先把「引擎输出的非周期性」查清楚：是逐块参数平滑的残留、限幅器增益的慢变、还是振荡器相位的浮点累积？找一个**已知纯正弦**的输出把它压到 −120 dB 以下（现有 THD 门禁能到 −122 dB，说明引擎本身够干净，问题多半在整秒对齐/块边界上）；
2. 然后用「同步参考法」测混叠：以主振频率的整数周期为窗，比较精确 bin 上的线能量与总能量，并把**上采样倍率与抽取滤波器**（当前 2× + 95 抽头 Kaiser，通带 19.2 kHz、阻带 −72 dB）的贡献分开量；
3. 只有第 1、2 步都干净了，才把「≤ −60 dB」写进门禁。

在那之前，门禁只断言上面「已证实可用」里的内容，评论里写明了这一项为何缺席。
