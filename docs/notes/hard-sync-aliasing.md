# 硬同步的混叠：两次失败、第三步与「达标」（P6.2b → P9.1c）

v1.84.0 交付了硬同步、sub 振荡器与噪声混合，但 P6.2 的验收里有一条**没有达成、也没有被门禁断言**：

> 频域（同步扫描的谐波结构与混叠 ≤ −60 dB）

后来它花了三步才完成：第一步把相位累加器改成 double，第二步找到「底噪其实是音符刚起振」，
第三步用**专用的带限同步振荡器**才真正把重启带限掉，让这条断言进了门禁。下面按时间顺序记录，
最后是达标的实测数字。

> **后续（v1.99.0，P9.1a）**：第三步的「达标」后来被证明是**抽到了好窗**——重启残余在同一个
> 持续音内会以约 24.5 s 为周期爆发到 −33 dB。见下面「⚠️ 更正」一节与 `docs/NEXT-PLAN-2.md`
> 的 **P9.1c**（新验收：每个 4 s 窗 ≥ −60 dB、≥30 s 离散度 < 3 dB）。

## 已证实可用（有断言）

- **同步确实锁相**：主振 220 Hz、从振 1.41×（非整数比）时，输出与「延后一个主周期的自己」相关系数 0.99（未同步时 0.24–0.50）；
- **从振自己的频率让位给主振网格**：未同步时 310 Hz 分量 0.037，同步后 0.00000（>20× 抑制）；
- **非整数比时才该抑制**（整数比本身就在网格上，这是正确行为，测试已按此区分）；
- **sub**：比基频低一个/两个八度，只有一条正弦（220 Hz 处比无 sub 高 50×，110 Hz 处 <1%），电平可控；
- **噪声混合**：非谐波能量 +55 dB，基频位置不动。

## 为什么混叠数字不可信

我最初的度量是「不在 220 Hz 谐波网格上的能量 / 总能量」，用 10 Hz 步长的单 bin 窗 DFT。这个度量**对任何信号都不成立**：

| 信号（220 Hz） | 该度量给出的「离网能量」 |
| :--- | ---: |
| 干净正弦 | −60 dB |
| 干净锯齿（门禁测得其混叠 −84 dB） | −41 dB |
| 硬同步锯齿 | −24 … −33 dB |

干净锯齿根本没有 41 dB 的混叠（现有门禁用另一种方法测得 −84 dB）。换成「整秒 + 矩形窗 + 精确谐波 bin」后，合成周期锯齿给出 −285 dB（度量本身正确），但引擎输出仍是：正弦 −60 dB、锯齿 −41 dB、同步 −24 dB。也就是说：**引擎输出在这一秒里不是严格周期的**，而那个「非周期性」的量级（−40…−60 dB）比我们想测的混叠（−60 dB）还大 —— 在这个噪声底之上无法断言 −60 dB。

## P6.2b 第一步：找到了底噪来源（v1.85.0）

用「整秒 + 矩形窗 + 精确谐波 bin」量**纯正弦**的离网能量（理论上应为 −∞）：

| 版本 | 纯正弦离网能量 | 说明 |
| :--- | ---: | :--- |
| f32 相位累加（原状） | **−66 dB** | 相位累加器的舍入误差是一次随机游走，表现为每个分音周围的裙边 |
| **f64 相位累加（已改）** | **−87 dB** | 每步误差从 ~1e-7 降到 ~1e-16，裙边整体下沉 21 dB |
| 参考：合成周期锯齿（解析） | −285 dB | 证明度量本身可以到 −280 dB 级，不是度量的极限 |

改动只有一处：vendored DaisySP `Oscillator` 的 `phase_/phase_inc_` 从 `float` 变 `double`（波形运算仍用 float，只在 Process 入口转一次）。**DSP 指纹（rms 0.030806 · 12 bands）没有变**，也就是说这是一次零兼容成本的质量提升。回归测试：`a_steady_sine_has_no_phase_noise_skirt` 断言纯正弦的离网能量 < −80 dB（f32 会立刻失败）。

## P6.2b 第二步：底噪其实是「音符刚起振」，不是稳态调制（v1.85.x）

上一版笔记里把 −92.5 dB 的一对 ±23.4 Hz 边带当成「乘性调制」并怀疑限幅器 —— **那是我自己的度量假象**：那些数字是用 Hann 窗单 bin 量的，±23.4 Hz（约 14 个 bin）处的 Hann 旁瓣本来就在 −95 dB 左右。改用**整秒 + 矩形窗 + 精确 bin**（无泄漏）后：

| 测量条件 | 纯正弦离网能量 |
| :--- | ---: |
| 起振后 21 ms（skip 8 块）开始量 | −69 dB |
| 起振后 0.53 s（skip 200 块）开始量 | **−90 dB** |
| 与之无关 | ENV_DECAY 0.2 / 0.001 结果相同 |

也就是说，底噪**不是稳态的**：音符刚起振时限幅器的峰值检波还在从起振瞬态恢复（保持 50 ms + 释放 150 ms），那段缓慢的增益变化正是离网度量会捡到的东西。等到音符稳定下来，底噪降到 −90 dB —— 比要测的 −60 dB 低 30 dB，**度量终于可用了**。

与此同时，上一版的 f64 相位累加（v1.85.0）把稳态底噪从 −66 dB 压到 −87…−90 dB，两者是叠加的。

## 稳定的测量结果：同步的真实混叠

条件：主振 220 Hz、从振 1.41×、音符稳定后取整秒、矩形窗 + 精确 bin。

| 信号 | 离网能量 |
| :--- | ---: |
| 未同步的从振（1.41×，本来就不在 220 网格上） | **−0.0 dB**（全部离网，说明度量确实在量「在不在网格上」） |
| 硬同步，锯齿从振 | **−32 dB** |
| 硬同步，方波从振 | −33 dB |
| 硬同步，三角从振 | −50 dB |
| 参考：同音高的普通锯齿（倍数比，本就在网格上） | −39 dB |

结论：**同步把从振拉回主振网格是有效的（−0.0 → −32 dB），但 −60 dB 的目标没有达成**；而且要注意参考值 —— 普通锯齿在这套度量下本来就在 −39 dB 附近，也就是说 **−32 dB 与「引擎自身锯齿的底子」同一量级**。要到 −60 dB，靠抽取滤波器已经不够了（当前 2× + 95 抽头 Kaiser，通带 19.2 kHz / 阻带 −72 dB），必须**把重启这个不连续点本身带限**（经典做法：在重启处做 BLEP/BLAMP 修正，用主振的越零小数位置决定修正量的位置与幅度），这也就是 P6.2b 剩下的第三步。

## P6.2b 第三步的第一次尝试：BLEP 修正重启点（失败，已回退）

思路是经典做法：重启是一个不连续点，所以在重启动用**两样本 polyBLEP 残差**把它带限——用主振越零的小数位置定残差的位置，用重启前后从振输出之差定残差的幅度，在 2 倍过采样域里减掉。

**实测反而更糟**：锯齿从振的离网能量从 **−32 dB 恶化到 −1.6 dB**（方波 −33 → −2.4，三角 −50 → −2.6）。已回退，没有进入提交。

调试输出（第一次重启的 `t / inc / before / value / step`）：

```
t=0.8716 inc=0.003231 before=-0.6983 value=0.2395 step=0.9378
t=0.2352 inc=0.003231 before=0.1751  value=0.9397 step=0.7647
t=0.5989 inc=0.003231 before=0.1774  value=0.6388 step=0.4613
t=0.9625 inc=0.003231 before=0.1798  value=0.0733 step=-0.1065
```

诊断：`t`、`inc`、`before` 都对（`before` 稳定在 0.176，正是 1.41 倍从振在重启那一刻的相位），但 **`value` 在每个周期剧烈变化（0.24 / 0.94 / 0.64 / 0.07…），而它本应稳定在 +1 附近**。原因是 DaisySP 自己的 polyBLEP 在 `t < inc` 时会把**波形值**从 +1 拉向 −1（那是它处理自身锯齿回绕的方式）——也就是说 `value − before` 量到的不是「重启这个不连续点」，而是「重启 + DaisySP 自己的平滑」的混合，我再用它去修正就成了二次修正，于是把一个周期信号修成了非周期。

**第二次尝试（按上面的思路：用裸波形估残差幅度）——同样失败，已回退**：

| 波形 | 不做 BLEP（当前实现） | 裸波形估残差的 BLEP |
| :--- | ---: | ---: |
| 锯齿 | −32 dB | **−1.9 dB** |
| 方波 | −33 dB | −33.5 dB（等于没改善） |
| 三角 | −50 dB | **−1.9 dB** |

结论：**在 DaisySP 的输出上打补丁这条路走不通**。原因很清楚——方波的两次跳变在 DaisySP 里各自已经被它的 polyBLEP 处理过，我再减一次「裸波形」的台阶等于把已经带限的信号又切开；锯齿更糟：它在重启点附近的平滑正是它带限的一半，用裸值去减就是过度修正。位置 `t` 是对的（两次尝试都验证了），错的是「在别人的输出上做减法」这个思路。

**P6.2b 第三步的正确形态（留给下一批，已写进 NEXT-PLAN）**：不要再修补 DaisySP，而是给同步做一个**专用的带限振荡器**——在桥接层（或 Rust 侧，用我们自己的 mipmap 波表）直接输出朴素波形，并在**同一个采样位置**同时做两件事：

1. 回绕本身的多项式 BLEP（这是 DaisySP 现在替我们做的），
2. 重启点的 BLEP/BLAMP 残差（位置用 `t`，幅度用同一套朴素波形的差值），

两者共享同一份相位与同一次「这一样本内发生了什么」的判断，就不会互相打架。做完用同一套稳定度量（整秒 + 矩形窗 + 精确 bin）重新量，目标 −60 dB。

**决策（v1.85.x）**：P6.2b 暂时**搁置**，把 P6.2 的「混叠 ≤ −60 dB」作为明确的技术债留在计划里，先推进后面的批次（P5.3 tempo map 等）；这样比继续在没有新思路的情况下反复试更划算。功能部分（同步/ sub / 噪声）已交付并有用例保护。

## P6.2b 第三步：专用带限同步振荡器（完成，达标）

按上一节写下的「正确形态」实现：`crates/synth-core/c_bridge/gs_daisy.cpp` 里的
`gs_voice_osc_sync_block` 不再调用 DaisySP 的 `Process()` 来产生从振，而是**自己发出朴素
波形**，再在**同一套相位判断**上同时补两类不连续：

- **从振自己的回绕**：锯齿/方波是 BLEP，三角是 BLAMP（斜率折点）；
- **主振回绕造成的重启**：值跳变用 BLEP，三角被折断的斜率用 BLAMP。

两类残差用同一张核表：启动时（`gs_daisy_init`）由窗化 sinc 低通（Blackman 窗，截止
0.22×过采样率 = 96 kHz 下的 21 kHz，正好压在 95 抽头抽取滤波器的 19.2 kHz 通带之上）
生成 step residual（`g_blep`）及其积分（`g_blamp`）。核在 ±32 个过采样样本上有支撑，
是非因果的；桥接层因此用一个 68 槽的环形累加器把朴素信号**延迟 32 个过采样样本**再
输出，等两次半步都到齐才落下来（直接截掉前导半核只剩 −41 dB，这就是为什么必须延迟）。
主振保持 DaisySP 自己的带限输出（它从不重启），但它的相位在桥接层用 double 跟踪，好让
重启落在主振精确的亚样本回绕点上。`Phase()`/`PhaseInc()` 是第一步留下的 double。

实测（主振 220 Hz、从振 1.41×、音符稳定 200 块后取整秒、矩形窗 + 精确 bin）：

| 波形 | 改动前（同步） | 现在（同步） | 未同步（对照） | 时域（相关系数 / 峰值 / 最大步进） |
| :--- | ---: | ---: | ---: | :--- |
| 锯齿 | −32.1 dB | **−72.3 dB** | −0.0 dB | 0.9995 / 0.122 / 0.116 |
| 方波（pw 0.5） | −33.5 dB | **−71.1 dB** | −0.0 dB | 0.9997 / 0.105 / 0.083 |
| 三角 | −49.5 dB | **−75.7 dB** | −0.0 dB | 0.9997 / 0.110 / 0.094 |

真 wasm（`scripts/verify-audio.mjs`）用这套「整秒 + 矩形窗 + 精确 bin」度量分别读到
**−68.7 / −68.6 / −77.3 dB**，门禁断言 `<-60 dB`，未同步对照 `>-3 dB`，并同时断言相关系数
`>0.95`、峰值 `≤1`、相邻样本最大步进 `<0.25`。Rust 单测
`hard_sync_keeps_the_slave_on_the_masters_grid` 用同一阈值。

### ⚠️ 更正（P9.1a，v1.99.0）：这些数字不是稳定属性

上面那组 −68.7/−68.6/−77.3 dB 是**抽到好窗**的结果。P9.1a 换了尺子（7 项 Blackman-Harris、
整 4 s 窗、每谐波 ±8 bin = ±2 Hz 的带外功率 / 总功率）并把场景钉死（全参数 pin + 清空 8 条
调制矩阵 + settle 400 块）之后，同一段**持续音之内**连续 8 个 4 s 窗读到：

```
BH-7 尺子：−109.2  −36.5  −48.3  −56.3  −105.3  −111.5  −117.0  −36.1  dB
旧尺子  ： −30.5  −36.2  −44.7  −50.3   −68.7   −68.7   −68.7  −36.2  dB
```

两套尺子**同步摆动**，所以波动在信号里，不在尺子里；旧尺子那个 −68.7 正是干净段读到的值，
而**坏窗可达 −33 dB**。一次 `note_on` 后连续 64 s（4 s 窗、1 s 步进）显示爆发起点在
0 / 24 / 49 s，即 **48 kHz 下周期约 24.5 s**，每次爆发约 11 s，中间约 13 s 读 −97…−119 dB；
只换采样率，周期变成 44.1 kHz ≈21 s、96 kHz ≈6 s。方波/三角同样（最差 −40.5 / −37.8 dB），
从振比值 1.41/1.5/1.7/**2.0（整数）**/3.3× 全部出现坏窗，16 次连续 `note_on` 的离散度 84 dB
（每次 `note_on` 都会从 `next_phases()` 取新初相，把漂移循环放在不同位置）。

**对照**：同一场景关掉同步（从振自由跑 310.2 Hz），8 个连续 4 s 窗对 310.2 Hz 自己的网格
**逐位相同**（−49.07 全同），8 次全新场景离散度 **0.00 dB**。所以漂移是**同步路径专有**的。

爆发能量落在离最近谐波 **10–300 Hz** 处（干净窗这里是 −124…−143 dB，泄漏在 2–10 Hz 环、
爆发窗那里反而只有 −117 dB），因此不是窗泄漏。初步判断是「重启点落在 2× 过采样网格上的
**亚样本位置缓慢滑移**」。这里有一个容易搞错的细节：DaisySP 的振荡器在 P6.2b 第一步已经把
`phase_` **与** `phase_inc_` 都改成了 double，桥接层对主振相位也用 double 跟踪，所以
「增量被 f32 舍入」这个直觉解释**站不住**——按 double/f32 相对误差估出的滑移时间都比实测的
24.5 s 差一个数量级以上，何况 220 Hz 的增量在 96 kHz 过采样域里是有理数。因此**慢变量的
确切身份至今没有定量解释**，P9.1c 的第一件事就是用临时调试导出把每次重启的亚样本位置量出来，
而不是先猜。已在 `docs/NEXT-PLAN-2.md` 立为 **P9.1c 硬同步重启对齐**：新尺子下**每个** 4 s 窗
≥ −60 dB、≥30 s 内窗间离散度 < 3 dB、16 次连续 `note_on` 离散度 < 3 dB，三种波形 × ≥4 个比值。

在此之前，门禁里那条同步断言**保留原度量与原 −60 dB 阈值不动**（在有利窗口下仍会通过），
但 `scripts/verify-audio.mjs` 的注释已写明它的真实性质，避免把幸运窗当成底。原始窗序列、
两种尺子对照、比值/波形/采样率消融与复现配方见仓库外的工作记录（P9.1a 交付时留在
`.tmp/hard-sync-drift.md`，未进版本库）。

未同步时逐位不变：`test:dsp` 的 `rms 0.030806`、`verify:presets` 的 81 指纹、
`verify:dsp:2x` 的 `0.030946` 都没有动（同步默认关闭，这条路径根本不执行）。

唯一代价是约 4 KB 代码与一段固定 BSS（核表在启动时填，不是动态全局构造），
`dist` 1672 KB 与 wasm gzip 70 KB 两个预算都仍然在原阈值内通过。

## （历史记录）曾被怀疑的「~23 Hz 乘性调制」

f64 之后，正弦的裙边仍由一对 **±23.4 Hz** 的边带主导（−92.5 dB，左右对称；±46.9 Hz 处 −118 dB）。23.4375 Hz = 48000/2048，而且它**与音量无关地保持 dB 值不变** —— 这是乘性（AM）的特征，不是加性噪声。嫌疑最大的是**限幅器的慢增益环**（它的检波/恢复时间常数决定这个频率）：即使信号峰值在拐点以下，增益也可能以极小的幅度随它自己的环路波动，于是给每个分音加上 ±f_loop 的边带。

下一步（P6.2b 第二步）：

1. 用「把限幅器排除在外」的路径量一次（例如临时把检波时间常数改掉、或直接读 `limit_gain` 的时间序列）确认 ±23 Hz 来自限幅器；若是，则让限幅器在拐点以下**增益严格等于 1 且不更新**（现在它显然在更新）。
2. 底噪压到 −120 dB 以下后，用同步参考法分开量「2× 上采样 + 95 抽头抽取滤波器」与「重启点对齐」各自的贡献。
3. 达标（≤ −60 dB）后把该断言写进门禁，P6.2 的验收才算完整。

在那之前，门禁只断言上面「已证实可用」里的内容，评论里写明了这一项为何缺席。
